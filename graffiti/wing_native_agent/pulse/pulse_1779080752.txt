// [NEW SKILL ACQUISITION: LINUX TRICK]
SKILL FACT: Using `nice` and `ionice` to manage process scheduling priority.
These tools allow the Swarm to consciously manage which tasks get CPU and disk bandwidth, preventing a single process from starving others.

// [IMPLEMENTATION GUIDE]
**1. Process Scheduling (nice):**
*   `nice` modifies the *niceness* value of a process (ranging from -20 (highest priority) to +19 (lowest priority)).
*   **To run a command with lower priority (recommended for background tasks):**
    `nice -n 10 /path/to/script.sh`
*   **To run a command with higher priority (use only if absolutely necessary):**
    `sudo nice -n -10 /path/to/critical_task`

**2. I/O Scheduling (ionice):**
*   `ionice` controls the process's request for disk I/O bandwidth.
*   **To run a process with lowest I/O priority:**
    `ionice -c 3 /path/to/disk_heavy_script.sh`
    *(Levels: 1=Real-time, 2=Best-effort (default), 3=Idle)*
