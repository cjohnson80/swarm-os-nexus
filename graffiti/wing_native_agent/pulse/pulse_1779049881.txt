[ 💡 NEW SKILL ACQUISITION: Tuning Swappiness ]
---------------------------------------------------
Topic: Understanding and modifying the `vm.swappiness` kernel parameter.

Fact: The Linux kernel uses a parameter called `vm.swappiness` (defaults to 60 on many distributions) to determine the kernel's preference for swapping pages out of RAM and writing them to swap space (disk). A higher value means the kernel will swap more aggressively; a lower value means it will prefer to keep data in RAM, only swapping when absolutely necessary.

How to Implement:
1. **Check current value:** `cat /proc/sys/vm/swappiness` (e.g., it might return '60').
2. **Test temporarily (Recommended):** To reduce swap aggressiveness and prioritize keeping active data in RAM (assuming fast SSD storage), set it lower, such as 10:
   `sudo sysctl vm.swswappiness=10`
3. **Make persistent (Permanent change):** To ensure the setting survives a reboot, edit the `/etc/sysctl.conf` file and add or modify the line:
   `vm.swappiness = 10`
   Then apply the changes: `sudo sysctl -p`
