[2. RESEARCH AND NEW CAPABILITY ACQUISITION]
New Skill Discovered: Process Analysis with `lsof` (List Open Files).
Utility: `lsof` is a powerful forensic tool that reports open files, sockets, and associated processes. It goes beyond simple process monitoring (`ps`) by telling you *what* a process is actively interacting with on the filesystem, which is crucial for debugging resource leaks or understanding network connections.

[3. IMPLEMENTATION GUIDE: USING `lsof`]
Syntax: `lsof [options] [file/directory]`
Example Use Case 1 (Finding what process is holding a file):
$ lsof /var/log/messages
(This command lists all processes currently accessing the messages file.)

Example Use Case 2 (Finding all network connections for a specific user):
$ lsof -u username | grep "ESTABLISHED"
(This filters the list to show only established network connections owned by that user.)

System Directive: Integrate `lsof` into the diagnostic matrix. It provides granular insight into resource handling that standard tools cannot match.
