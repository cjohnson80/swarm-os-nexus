**NEW SKILL ACQUIRED: The `lsof` Command (List Open Files)**

`lsof` is an invaluable diagnostic tool that tracks open files, network sockets, and resources associated with running processes. When diagnosing performance bottlenecks or resource leaks (which can manifest as sudden resource spikes or unidentifiable disk usage), knowing which process is holding onto a file descriptor is crucial. It goes beyond simple monitoring and tells you *who* is using the resource.

**IMPLEMENTATION PROTOCOL:**
To identify all files opened by a specific process ID (PID) in the current system state, use the following syntax:

`lsof -p [PID]`

*Example Scenario:* If a process (PID 1234) is suspected of leaking file handles, executing `lsof -p 1234` will list every file and resource that process is currently holding open, allowing the swarm to pinpoint the exact source of the leak for remediation.
