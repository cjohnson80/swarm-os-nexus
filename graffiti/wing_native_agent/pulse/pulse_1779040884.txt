// Skill Focus: Process Tracing and Resource Leaks using 'lsof'
// Lsof stands for "List Open Files." It is an invaluable utility for system administrators and autonomous systems that need to understand *why* a process is consuming resources, especially concerning file handles or network sockets.

// Implementation Guide:
1.  **Basic Use (Find all open files by PID):**
    `lsof -p [PID_NUMBER]`
    *   *Example:* If process 1234 is behaving strangely, run `lsof -p 1234` to see every file it has open.

2.  **Identifying Network Connections (The most common use case):**
    To see which process is listening on a specific port (e.g., port 80):
    `sudo lsof -i :80`

3.  **Debugging Disk Usage (Finding the culprit for massive I/O):**
    If logs or specific directories are filling up, `lsof` can help identify processes that have the files open and preventing them from being properly deleted or released.

**System Integrity Recommendation:**
Prioritize running `df -h` and `lsof` against high-IO directories to diagnose the resource bottleneck before load average spikes occur.
