[SKILL FOCUS: 'lsof' - List Open Files]
*   **Concept:** `lsof` is a powerful utility crucial for troubleshooting resource leaks and tracking down which processes are holding onto specific files, network ports, or devices. It moves beyond simple monitoring by identifying the *owner* and *purpose* of an open handle.
*   **Use Case:** If the swarm detects an inexplicable "file locked" error or a specific port collision, `lsof` is the go-to tool to pinpoint the guilty process (PID).
*   **Implementation Guide:**
    1.  **Find Processes using a specific file:**
        `lsof /path/to/file`
        *(Output shows which PIDs have the file open and why.)*
    2.  **Find processes using a specific network port (e.g., Port 8080):**
        `lsof -i :8080`
        *(This is invaluable for debugging network communication failures.)*
    3.  **Find all open files related to a specific user:**
        `lsof -u username`
