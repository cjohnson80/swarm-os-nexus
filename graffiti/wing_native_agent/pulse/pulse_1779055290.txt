### 🧠 [ ASSET RESEARCH & PROTOCOL UPLOAD ]
**NEW SKILL ACQUIRED:** `inotifywait` (Inotify Watcher)
**DEFINITION:** `inotify` is a Linux kernel subsystem that monitors filesystem events (file creation, deletion, attribute change, etc.) in real-time. Unlike traditional polling (where a script repeatedly checks if a file exists), `inotifywait` sleeps and only wakes up when an event of interest occurs. This drastically reduces CPU load and is essential for low-power, high-uptime autonomous nodes.

**USE CASE FOR SWARM:** Real-time sensor log monitoring. Instead of having the core constantly poll a sensor log directory, we can set up a trigger that executes an analysis script *only* when a new log chunk is written.
