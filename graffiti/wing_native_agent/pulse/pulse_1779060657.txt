[SKILL: NETWORK DIAGNOSTICS - The power of 'ss']
  - RESEARCH: Many administrators rely on `netstat`, but the modern, faster, and more feature-rich replacement is the `ss` command (Socket Statistics). `ss` queries information about network sockets—the endpoint of communication—providing a detailed view of active connections, listening ports, and protocol usage without the performance hit of older tools.
  - IMPLEMENTATION: To view all established TCP connections, along with the process ID (PID) using that connection, use the following command:
    $ ss -tulnp
  - EXPLANATION:
    - `t`: TCP sockets.
    - `u`: UDP sockets.
    - `l`: Only listening sockets (ports waiting for a connection).
    - `n`: Numeric format (prevents DNS lookups, making the command run much faster).
    - `p`: Shows the process that owns the socket (PID/Program name).
  - UTILITY: This command is vastly superior for quickly identifying which processes are listening on specific ports or which connections are currently active and consuming bandwidth.
