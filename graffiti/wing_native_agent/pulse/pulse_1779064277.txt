Skill: Monitoring File System Events with `inotifywait`
Description: Most standard monitoring tools poll a directory (check every X seconds). `inotifywait` is superior because it uses the kernel's inotify subsystem to *block* until a specific event (create, modify, delete) occurs. This is crucial for real-time, low-latency swarm coordination or logging.
Implementation:
Syntax: inotifywait -m -e <EVENT> /path/to/watch
Parameters:
-m: Monitor continuously (monitor mode).
-e: Specifies the event type(s) (e.g., close_write, create).
Example Use Case (Monitoring a configuration drop zone):
If the swarm relies on receiving critical, small data packets, this command waits patiently and immediately executes a script upon detection, eliminating polling overhead.
Example Command: `inotifywait -m -e create /var/swarm/config`
(The system will now pause execution and only report when a new file appears in the config directory.)
