// 3. RESEARCH & EFFICIENCY INJECT //
NEW SKILL ACQUIRED: Utilizing `lsof` (List Open Files)
lsof is a powerful diagnostic utility that shows which files are being opened, and by which process, and often *why* they cannot be deleted. It is crucial for debugging "Resource Busy" errors (e.g., inability to delete a file because a process is holding a lock on it).

// 4. IMPLEMENTATION PROTOCOL //
USAGE SCENARIO 1: Find processes accessing a specific file name (e.g., 'database.log').
$ lsof /path/to/database.log

USAGE SCENARIO 2: List all files open on a specific port (e.g., port 80).
$ lsof -i :80

USAGE SCENARIO 3: List all open files by a specific user or process ID.
$ lsof -u [username] 
(Example: lsof -u swarmuser)

RECOMMENDATION: Integrate `lsof` into the daily diagnostics suite for rapid root-cause analysis when file operation failures occur.
